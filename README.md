# 🤝 Donate Bangladesh – Online Donation Platform

A responsive and user-friendly web application designed to support emergency relief and humanitarian causes in Bangladesh. From flood relief to social movement aid, this platform allows people to contribute easily and securely.

---

## 🌍 Project Summary

**Donate Bangladesh** is a donation platform aimed at connecting donors with urgent causes in different parts of the country. This includes natural disasters like floods and social issues like the Quota Movement. Each cause includes a description, a donation amount field, and a success confirmation message.

---

## 🎯 Features

- ✅ Clean and intuitive UI for easy navigation
- ✅ Dynamic donation input for multiple causes
- ✅ Real-time confirmation after successful donation
- ✅ Organized content for each campaign
- ✅ Mobile-responsive layout
- ✅ Clear and impactful call-to-actions (CTA)
